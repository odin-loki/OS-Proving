# Errors found, and how many

Generated by `tools/gen_errors_report.sh` from the data tables in `data/`. Every count below is read from those tables by script, except the ones marked **(agent-reported)**, which come from the hand-off reports of the reading agents and are approximate.

Scope: 1135593 functions of Linux, FreeBSD/HardenedBSD and KDE with a machine-written annotation (prose summary and, where possible, a formal contract). "Error" here means one of two things: a wrong annotation (the claim about the function does not match its code), or a possible defect in the source itself (flagged by a reader, not confirmed).

## 1. Wrong annotations: how many of the original claims were wrong

| Measure | Functions |
|---|---|
| Original annotations | 1135593 |
| Failed at least one check, or a reviewer disagreed (before repair) | 173356 (15.3%) |
| Passed every check that could judge them | 415923 |
| No check could judge them (prose only) | 546314 |

Where the first-round failures came from (a function can fail several checks):

| Check | Failed | Passed or agreed |
|---|---|---|
| Mechanical (name in slice, contract names that exist, no `ensures true`, error codes, `result` on void) | 55307 | 1080286 |
| Contract grammar | 23105 | 123342 |

| Random testing of pure integer helpers (200,000 inputs each) | 712 counterexamples | 1586 |
| Independent model cross-check (DeepSeek reads code and annotation) | 95572 disagreements | 379414 agreements |

Typical findings (counts from the verification report, step 1): contracts naming identifiers that do not exist in the file 26,311; function name not in its slice 8,525; no `requires` 8,041; `ensures true` 5,918; non-C names 4,683; prose error codes missing from the formal contract 3,317; `result` on a void function 1,058. Of 695 random-test counterexamples, 257 were wrong for ordinary inputs (for example a contract that claims `0x0f1e0ffa` where the code yields `0xfa1e0ff3`) and 436 only at integer limits. 1,875 contracts had an operator-precedence bug.

Waves 1 to 3 had agents read the real source for each queued function (about 8,700 functions). Counts for wave 3 (packets P0145 to P0212, 2,735 functions, 121 dropped as non-functions) as the agents tallied them; waves 1 and 2 were not tallied the same way.

| Finding | Count (agent-reported) |
|---|---|

| Macro-generated functions that needed the macro head as their name | about 200 |

The reviewer (a different model) was right on roughly 70 to 90 per cent of the claims it made, depending on the packet. The agents' second pass was mostly a keyword sweep for unqualified words rather than a full re-read, so these fixes are drafts until independently re-read; that is why the next step is a large random audit.

## 7. What this document does not claim

- It does not claim the unchecked functions are correct. "Verified" means the annotation passed the checks and an independent reviewer; "proved" is reserved for machine-checked proofs.
- Counts marked agent-reported are the agents' own tallies. They are indicative, not audited.
